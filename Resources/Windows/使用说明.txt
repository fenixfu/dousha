Dousha for Windows — 按住说话，松开上屏
========================================

【开始使用】
1. 把整个 Dousha 文件夹放到任意位置（不要只拷 exe，旁边的 DLL 都需要）。
2. 双击 dousha-win.exe —— 右下角托盘会出现一个图标，没有别的窗口，这是正常的。
   只双击一次！重复双击不会多开（有单实例保护），但也没有必要。
3. 把光标点进任何输入框（微信、浏览器、Word 都行），按住【右 Ctrl】说话，
   屏幕底部会浮出一个小条实时显示识别结果；松开按键，文字自动打进输入框。

【设置 / 换按键】
右键托盘图标可以：
  - 打开设置文件
  - 打开日志文件夹
  - 重新加载设置
  - 重置豆包凭据
  - 关于 Dousha
  - 退出 Dousha

配置文件在：C:\Users\你的用户名\AppData\Local\Dousha\config.json
（资源管理器地址栏粘贴 %LOCALAPPDATA%\Dousha 直达；也可以右键托盘图标 → 打开设置文件）

把 "hotkey" 改成下面任意一个，保存后右键托盘图标 → 重新加载设置；如果没有生效，再退出重开：
  rightctrl  leftctrl  rightshift  leftshift  rightalt  leftalt
  capslock  f8  f9  f10  scrolllock  pause

"swallowHotkey": true 表示按住期间这个键不会传给别的程序（推荐保持 true）。

【没反应？按顺序检查】
1. 托盘有图标吗？没有就是没启动成功。
2. 说话时底部小条出现了但一直没字 / 提示「没听到声音」：
   九成是【默认麦克风】不对。右键任务栏喇叭 → 声音设置 → 输入，
   选你真正的麦克风。特别注意：装过 Steam 的电脑经常被默认成
   "Steam Streaming Microphone"，那是个没有声音的虚拟设备。
3. 系统设置 → 隐私和安全性 → 麦克风：最上面的总开关和
   「允许桌面应用访问麦克风」都要打开（Dousha 不会出现在应用列表里，
   桌面程序走的是总开关，这是正常的）。
4. 还不行的话，命令行运行自检：
     dousha-win.exe --doctor
   它会逐项检查网络、凭证、识别服务，并告诉你哪一步挂了。
5. 日志在 %LOCALAPPDATA%\Dousha\Logs\dousha.log，发给开发者就能定位（也可以右键托盘图标 → 打开日志文件夹）。

【粘贴到 WSL / Linux 图形应用】
如果要把文字贴进 WSLg / Xwayland / Xfce 等 Linux 图形窗口（窗口标题通常以
"Xwayland on :" 开头），Dousha 默认会自动改成发送 Alt+V，而不是 Ctrl+V。

你需要在 Linux 侧做一个「桥接脚本」，把 Windows 剪贴板内容转写到 X11 剪贴板，
再触发粘贴。经测试可用的脚本如下（需要安装 xclip、xdotool）：

  #!/bin/bash
  raw=$(/mnt/c/Windows/System32/WindowsPowerShell/v1.0/powershell.exe -NoProfile -Command \
      '[Console]::OutputEncoding = [System.Text.Encoding]::UTF8; Get-Clipboard -Raw' \
      2>/dev/null | tr -d '\r')
  if [ -n "$raw" ]; then
      printf '%s' "$raw" | xclip -selection clipboard -target UTF8_STRING
      xdotool key --clearmodifiers --delay 1 ctrl+shift+v
  fi

把脚本存到 WSL 里（例如 ~/.local/bin/dousha-bridge.sh），加上可执行权限，
然后在 Xfce / 你的桌面环境里把 Alt+V 绑定到这条命令：

  /home/你的用户名/.local/bin/dousha-bridge.sh

窗口标题前缀和快捷键可以在 config.json 里改：
  xwaylandWindowTitlePrefix: "Xwayland on :"
  xwaylandPasteShortcut: "alt+v"

如果 Linux 窗口不是 Xwayland（标题不匹配），Dousha 会继续发送普通 Ctrl+V。

【退出】
右键托盘图标 → 退出。
