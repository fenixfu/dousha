# Double-tap-and-hold Left Control trigger

The Windows MVP will default to a double-tap-and-hold Left Control trigger for push-to-talk. A single Left Control press conflicts with common Windows shortcuts, while Right Control is absent on some keyboards; the double-tap-and-hold gesture preserves press-and-hold dictation without treating normal Control shortcuts as dictation attempts, at the cost of requiring a low-level keyboard hook instead of a simple registered hotkey.
